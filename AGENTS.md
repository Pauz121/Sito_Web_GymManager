# GymManager Website policy

This project inherits the AGENT-IA master policy when checked out in its workspace. Codex owns integration, security, tests, Git and final acceptance.

## Scope
Public five-page static Italian product website. HTML/CSS/vanilla JavaScript, no framework, package installation or runtime backend. Keep Desktop and both native iOS application sources outside this repository. No pricing, checkout, tracking, invented product claims or fabricated footage.

## Source and build
Reuse existing HTML, shared CSS/JS and approved real/demo media. Public output is ONLY the allowlisted dist/ generated by node scripts/prepare-public.mjs. Do not publish the repository root. Preview: node scripts/serve-site.mjs --public. Validation: node scripts/validate-site.mjs and node --test scripts/site.test.mjs scripts/legal.test.mjs scripts/trainer-video.test.mjs (FFprobe required for media tests). HTTP validation: node scripts/test-http.mjs with preview running. Commands must be verified before claiming PASS.

## Protected content
Never commit .env*, credentials, tokens, original uploads/recordings, QA captures, machine state, logs, build output or local CODEX_HANDOFF.md. Public GitHub release endpoint/repository is browser configuration, not authentication. Never add a GitHub token to frontend JavaScript.

## UX and privacy
Preserve the established warm neutral/charcoal/red identity, responsive layouts, accessible native controls, keyboard focus, text alternatives and reduced motion. Real media only; review privacy before publication. Privacy/Support remain explicitly marked approved drafts until the owner approves definitive content and HTTPS destination; never invent a domain.

## Hosting and boundaries
Render Static Site preparation only unless explicit deployment approval is given. Follow current official docs. No database, Supabase, application release or App Store action in website work. No destructive Git, force push or history rewrite. Commit/push/deploy need explicit user authority.

## Delegation and continuity
Codex defines narrow advisory/implementation scope and reviews every result; no delegated Git/deploy/secret operations. Gemini analysis is optional if unavailable; record actual failures, never pretend success. Update ignored local CODEX_HANDOFF.md after meaningful phases, preserving previous task state and explicit database NONE.
