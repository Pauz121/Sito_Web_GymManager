Aggiornamenti

La versione nuova arriva senza cambiare questo sito.

La pagina interroga la release stabile più recente, ignora draft e prerelease e sceglie l'installer Windows destinato all'utente. I file di firma e i metadati dell'updater non vengono proposti come download principale.

Download sempre aggiornato

Versione, data e collegamento vengono letti dalla release pubblica al caricamento della pagina. Nessun token GitHub è presente nel browser.

Aggiornamenti dall'app

Una volta installato, GymManager può verificare la presenza di nuove versioni attraverso il sistema di aggiornamento configurato nel client Desktop.

Nota Windows

Controlla sempre la provenienza del file.

L'installer è distribuito dal repository ufficiale GymManager. Finché la reputazione dell'app non è consolidata o non è presente una firma Authenticode riconosciuta, Windows potrebbe mostrare un avviso di sicurezza. Leggi il messaggio e verifica nome e provenienza del file; se il sistema lo blocca, non disattivare le protezioni e chiedi assistenza.
